# Requirements (EARS)
1. WHEN a nurse asks a path question, THE SYSTEM SHALL answer with short facts and source links.
2. WHEN a fact is uncertain, THE SYSTEM SHALL mark it as uncertain.
3. THE SYSTEM SHALL NOT invent salaries, wait times, or acceptance rates.
4. WHEN viewing country paths, THE SYSTEM SHALL cover at least US, AU, NZ, SG.
5. THE SYSTEM SHALL expose a working public URL for judges.
