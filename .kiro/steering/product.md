# Product
Nurse Path Frankenstein — a queryable agent that stitches official nurse-overseas pathways (US / Australia / New Zealand / Singapore licenses, CPT-style study tracks, EB-3 employer sponsorship) into one place so a nurse can ask "what do I need next" and get sourced facts, not hype.

Audience: Chinese-speaking nurses exploring overseas careers.
Non-goals: legal advice, guaranteed visas, fake stats.
Category: Frankenstein (stitching path-intel + agent UX that don't usually ship together).
