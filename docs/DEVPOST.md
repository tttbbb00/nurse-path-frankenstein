# Devpost draft — Nurse Path Frankenstein

## Project name
Nurse Path Frankenstein

## Tagline / short description
Stitches official nurse overseas pathway facts (US · Australia · New Zealand · Singapore licenses + high-level work/visa hubs) into one chat-style agent UI — citations on every card, uncertain items marked, no invented numbers. Built with Kiro steering, specs, and hooks.

## Hackathon category
**Frankenstein** (primary) — path-intel knowledge cards + agent Q&A UX that don’t usually ship together.

Bonus tracks to attempt (when publishing): Blog · Social Blitz.

## Built with
- Kiro (`.kiro/steering`, `.kiro/specs/nurse-path`, `.kiro/hooks`)
- TypeScript + Vite (vanilla)
- Local markdown / JSON fact cards (`knowledge/`, `web/src/data/facts.ts`)
